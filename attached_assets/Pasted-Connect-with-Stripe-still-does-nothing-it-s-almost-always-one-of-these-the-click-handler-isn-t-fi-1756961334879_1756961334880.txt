Connect with Stripe still does nothing, it’s almost always one of these:

the click handler isn’t firing (button submitting a form, or not bound),

the API route isn’t being hit (404/405) or is failing (500),

the API is running on Edge instead of Node (Stripe SDK can’t run on Edge),

your request is missing userId/providerId/applicationId, the server returns 400, and the client swallows it,

the server returns {success:true} but no url.

Below is a quick, copy-paste fix + a 2-minute diagnostic to prove each hop.

B) Server: force Node runtime, add a GET health check, and log

In app/api/payout/start/route.ts:

export const runtime = "nodejs";        // Stripe requires Node, not Edge
export const dynamic = "force-dynamic"; // no caching

import { NextRequest, NextResponse } from "next/server";
import Stripe from "stripe";
import { createClient } from "@supabase/supabase-js";

const ORIGIN =
  process.env.NEXT_PUBLIC_APP_URL ||
  "https://"+(process.env.REPL_SLUG && process.env.REPL_OWNER ? `${process.env.REPL_SLUG}.${process.env.REPL_OWNER}.repl.co` : "localhost:3000");

const supabase = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SERVICE_ROLE_KEY!);

// ✅ Health check: open /api/payout/start in the browser; expect {ok:true}
export async function GET() {
  return NextResponse.json({ ok: true, origin: ORIGIN });
}

export async function POST(req: NextRequest) {
  try {
    const body = await req.json();
    console.log("[payout/start] body", body);
    const { userId, providerId, applicationId, accountType } = body;

    if (!userId || !providerId || !applicationId) {
      return NextResponse.json({ success:false, message:"Missing userId/providerId/applicationId." }, { status:400 });
    }

    const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!, { apiVersion: "2024-06-20" as any });

    // Fetch provider
    const { data: provider, error: pErr } = await supabase
      .from("providers")
      .select("id, stripe_account_id")
      .eq("id", providerId)
      .single();
    if (pErr) throw pErr;

    let accountId = provider?.stripe_account_id;

    if (!accountId) {
      const acct = await stripe.accounts.create({
        type: "express",
        capabilities: { transfers: { requested: true }, card_payments: { requested: true } },
        business_type: accountType === "business" ? "company" : "individual",
        metadata: { providerId, userId, applicationId },
      });
      accountId = acct.id;
      const { error: updErr } = await supabase
        .from("providers")
        .update({ stripe_account_id: accountId })
        .eq("id", providerId);
      if (updErr) throw updErr;
    }

    const link = await stripe.accountLinks.create({
      account: accountId!,
      type: "account_onboarding",
      return_url: `${ORIGIN}/services/onboarding/details?from=stripe`,
      refresh_url: `${ORIGIN}/services/onboarding/payout?refresh=1`,
    });

    console.log("[payout/start] accountLink", link);

    if (!link?.url) {
      return NextResponse.json({ success:false, message:"Stripe returned no onboarding URL." }, { status:500 });
    }

    // Mark step started (best-effort)
    await supabase
      .from("provider_applications")
      .update({ step5_status: "started", updated_at: new Date().toISOString() })
      .eq("id", applicationId)
      .eq("user_id", userId);

    return NextResponse.json({ success:true, url: link.url });
  } catch (e:any) {
    console.error("[payout/start] ERROR", e);
    return NextResponse.json({ success:false, message: e?.message || "Internal error" }, { status:500 });
  }
}

D) Common gotchas (fast checks)

Button lives inside <form> → add type="button".

Route file path must be app/api/payout/start/route.ts (App Router).

Missing env vars: STRIPE_SECRET_KEY, NEXT_PUBLIC_APP_URL, NEXT_PUBLIC_SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY.

Route running on Edge → add export const runtime = "nodejs";

Server returns {success:true} but url missing → client should throw “Stripe onboarding URL missing”.
