2. If the row is updated but UI is stale
Your profile page probably fetches the data once on page load, then stores it in React context or state. Two common fixes:

A) Quick reload trick (no code)
Hard-refresh the running preview tab (⌘⇧R / Ctrl+Shift+R).

If you still see the old name, log out → log back in (forces a new profile fetch).

B) One-liner refetch on mount (recommended)
Add a select('*', { head: false }) call right after sign-in or page navigation so the client always pulls the latest row:

tsx
Copy
Edit
// inside useEffect of ProfilePage.tsx (or wherever you load profile)
useEffect(() => {
  (async () => {
    const { data: session } = await supabase.auth.getSession();
    const { data: profile } = await supabase
      .from('profiles')
      .select('*')
      .eq('id', session.user.id)   // your PK
      .single();                   // <- ensures one row

    setProfile(profile);           // update state
  })();
}, [location.pathname]);            // refetch whenever route changes
