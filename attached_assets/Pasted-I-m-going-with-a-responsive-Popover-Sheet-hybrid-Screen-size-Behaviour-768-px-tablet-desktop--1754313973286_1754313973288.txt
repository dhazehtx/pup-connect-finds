I’m going with a responsive Popover → Sheet hybrid
Screen-size	Behaviour
≥ 768 px (tablet / desktop)	Neat Popover anchored to the Sort pill – feels like classic e-commerce UI and lets shoppers compare options without losing scroll position.
< 768 px (phones)	The same component automatically stretches to a full-width bottom sheet (sliding up 35 % height). It’s thumb-friendly, avoids covering the pill rail, and matches the motion pattern you use for the Filter side-sheet.

Because it’s one component that adapts with a single CSS media query, you maintain parity across devices without duplicating code.

// components/SortPopover.tsx
import * as Popover from '@radix-ui/react-popover';
import { useState } from 'react';

const sortOptions = [
  'Featured',
  'Price ↑',
  'Price ↓',
  'Rating',
  'Newest',
] as const;

export default function SortPopover() {
  const [sort, setSort] = useState<typeof sortOptions[number]>('Featured');

  return (
    <Popover.Root>
      {/* Trigger pill --------------------------------------------------- */}
      <Popover.Trigger asChild>
        <button className="
          btn-outline
          px-4 py-1.5 rounded-full flex items-center gap-1
          transition
        ">
          {sort} ▾
        </button>
      </Popover.Trigger>

      {/* Popover / sheet ------------------------------------------------ */}
      <Popover.Portal>
        {/* Backdrop for the mobile sheet */}
        <Popover.Overlay className="
          md:hidden fixed inset-0 bg-black/40 animate-fadeIn
        " />

        <Popover.Content
          side="bottom"
          align="end"
          sideOffset={8}
          className="
            z-30 w-48 rounded-xl bg-white shadow-lg p-4 space-y-1
            animate-scaleIn origin-top-right
            md:w-44
            /* === mobile sheet override === */
            md:relative
            fixed md:static bottom-0 inset-x-0 md:inset-auto
            md:rounded-xl rounded-t-2xl
            md:animate-none animate-slideUp
          "
        >
          <h3 className="text-center font-medium mb-3 md:hidden">
            Sort products
          </h3>

          {sortOptions.map(opt => (
            <button
              key={opt}
              onClick={() => { setSort(opt); }}
              className={`
                w-full text-left px-3 py-2 rounded-lg
                hover:bg-gray-50
                ${opt === sort ? 'font-semibold text-primary-600' : ''}
              `}
            >
              {opt}
            </button>
          ))}

          {/* mobile “Done” button */}
          <button
            onClick={() => Popover.close()}
            className="
              md:hidden mt-3 block w-full rounded-full bg-primary-600
              text-white py-2 font-semibold
            "
          >
            Done
          </button>
        </Popover.Content>
      </Popover.Portal>
    </Popover.Root>
  );
}
How it works
Popover.Content is always rendered; CSS decides the look:
*md:* classes apply from the md breakpoint upward (desktop), keeping it a 200 px-wide popover next to the pill.
*Below md, fixed-position rules convert it into a bottom sheet (fixed bottom-0 inset-x-0 … rounded-t-2xl).

Animations – two tiny Tailwind utilities you can add to tailwind.config.js:

theme: {
  extend: {
    keyframes: {
      slideUp: { from:{transform:'translateY(100%)'}, to:{transform:'translateY(0)'} },
      scaleIn: { from:{opacity:0, transform:'scale(.95)'}, to:{opacity:1, transform:'scale(1)'} },
      fadeIn: { from:{opacity:0}, to:{opacity:1} },
    },
    animation: {
      slideUp: 'slideUp 200ms ease-out',
      scaleIn: 'scaleIn 150ms ease-out',
      fadeIn: 'fadeIn 150ms',
    },
  },
},
