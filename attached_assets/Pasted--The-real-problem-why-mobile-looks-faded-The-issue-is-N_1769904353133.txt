🚨 The real problem (why mobile looks faded)

The issue is NOT the SVG stroke color.
The issue is THIS wrapper layer:

<div
  className="relative w-24 h-24 rounded-3xl flex items-center justify-center shadow-2xl pup-box-icon-container"
  style={{
    background: 'rgba(255, 255, 255, 0.2)',
    backdropFilter: 'blur(12px)',
    WebkitBackdropFilter: 'blur(12px)',

Why mobile breaks:

Mobile Safari reduces opacity + blur strength

rgba(255,255,255,0.2) becomes almost invisible

The icon sits on a light gradient → looks gray/faded

Desktop hides this problem because it renders blur differently.

🎯 Fix strategy (the ONLY fix that works)

We must force the icon container to use the SAME gradient as the card, not translucent white.

That means:

❌ Remove white glass background

❌ Remove blur

✅ Apply the blue-violet gradient inline (so mobile can’t override it)
