5) Why the demo showed while signed-in (what likely happened)
The previous code probably did const providers = live || DEMO, which still shows demo when your live API returns an empty array (truthy/falsy confusion).

Or it fetched live even as a guest and then appended demo, mixing both.

The pattern above prevents both by:

Disabling the fetch entirely when !isSignedIn (useSWR(null, …)).

Choosing providers = isSignedIn ? live : DEMO—no fallback mixing.
