1) Centralize Palette (Tailwind + CSS variables)

Edit tailwind.config.js to define tokens used on desktop and make all breakpoints consume them:

// tailwind.config.js
module.exports = {
  content: ["./src/**/*.{js,ts,jsx,tsx}"],
  theme: {
    extend: {
      colors: {
        primary: {
          50:  'var(--color-primary-50)',
          100: 'var(--color-primary-100)',
          200: 'var(--color-primary-200)',
          300: 'var(--color-primary-300)',
          400: 'var(--color-primary-400)',
          500: 'var(--color-primary-500)', // desktop blue
          600: 'var(--color-primary-600)',
          700: 'var(--color-primary-700)',
          800: 'var(--color-primary-800)',
          900: 'var(--color-primary-900)',
        },
        surface: {
          DEFAULT: 'var(--color-surface)',
          alt:     'var(--color-surface-alt)',
          card:    'var(--color-surface-card)',
        },
        text: {
          DEFAULT: 'var(--color-text)',
          muted:   'var(--color-text-muted)',
          inverse: 'var(--color-text-inverse)',
        }
      },
      borderRadius: { card: '14px' }
    }
  },
  plugins: []
}


In your global CSS (e.g., src/styles/globals.css), set variables to match desktop’s palette (adjust hexes if your desktop uses slightly different blues/grays):

:root {
  /* Primary desktop blue */
  --color-primary-500: #2663eb;
  --color-primary-600: #1f4fc2;
  --color-primary-700: #173e98;

  /* Surfaces from desktop */
  --color-surface:      #ffffff;  /* app/page background */
  --color-surface-alt:  #f5f7fb;  /* light section bg */
  --color-surface-card: #ffffff;  /* cards, banners */

  /* Typography */
  --color-text:         #0f172a;  /* slate-900 */
  --color-text-muted:   #64748b;  /* slate-500 */
  --color-text-inverse: #ffffff;  /* on blue buttons */
}
html, body, #root { background: var(--color-surface); color: var(--color-text); }

2) Purge Yellow Everywhere (search & replace)

Replace all of the following with neutral/primary tokens:

bg-yellow-* → bg-surface or bg-surface-card (match desktop)

text-yellow-* → text-primary-600 or text-text

from-yellow-* / to-yellow-* (gradients) → match desktop gradient or remove

Inline hexes: #FF0, #FFFF00, #FFD700, #FFEB3B, #FDE047, #FACC15, #F59E0B → remove/replace

Utility aliases like bg-warning, text-warning used as base backgrounds → remove/replace

Delete any mobile-only CSS (media queries or .mobile-*) that sets yellow backgrounds/highlights.
