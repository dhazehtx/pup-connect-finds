Here’s what’s still happening — and the one-time, copy-paste fix that will turn every active pill label and the FAB-cart icon to white without reopening this issue again.

Why we keep missing the pill text
Radix adds its own utility text-primary-foreground after Tailwind compiles, so whatever we inject earlier (text-white) keeps getting overwritten.

The cart icon is an SVG that inherits the current color. When the FAB is blue, the icon inherits the default blue token because we never set color explicitly.

Permanent solution (works everywhere)
Tell Tailwind that whenever data-state="active" on a Radix tab,
the text should be white.
That produces a compiled rule that wins over the runtime class Radix appends.

Give the SVG an explicit text-white class so its stroke inherits white.

### TASK: force white on active pill labels + cart icon

SCOPE
• tailwind.config.ts           (add one variant + safelist)
• components/layout/CartFab.tsx (add text-white to SVG)
• NO other files

STEPS
1. tailwind.config.ts
   ---------------------------------
   const plugin = require('tailwindcss/plugin')

   module.exports = {
     content: ['./client/src/**/*.{tsx,ts,jsx,js}'],
     theme: { extend: {} },
     safelist: ['data-[state=active]:text-white'],
     plugins: [
       plugin(function ({ addVariant }) {
         addVariant('radix-active', '&[data-state="active"]')
       }),
     ],
   }
   ---------------------------------
   (The safelist guarantees the class survives purge; the variant lets us use
   `radix-active:text-white` in JSX.)
