Below are three alternate UI patterns you can swap in for the “Price (Low→High)” pill that’s on the Store tab now. Each is keyboard-accessible, mobile-friendly, and fits your blue/white design system.

1 Inline Segmented Control

Price ↑   |   Price ↓   |   Rating   |   Newest
one-tap switch, no extra pop-over

best when you have ≤ 4 sort modes

Copy
Edit
// components/SortSegment.tsx
import clsx from 'clsx';
const modes = ['Featured','Price ↑','Price ↓','Rating'] as const;

export default function SortSegment({value,setValue}:{value:string,setValue:(s:string)=>void}){
  return (
    <div className="border rounded-full inline-flex overflow-hidden">
      {modes.map(m=>(
        <button
          key={m}
          onClick={()=>setValue(m)}
          className={clsx(
            'px-3 py-1.5 text-sm',
            value===m ? 'bg-primary-600 text-white' : 'text-primary-600'
          )}>
          {m}
        </button>
      ))}
    </div>
  );
}
Place it where the current Sort pill sits — it’s always visible and takes ~260 px.

      className={clsx(
        'px-3 py-1.5 rounded-full whitespace-nowrap border',

Add scrollbar-hide to Tailwind (::-webkit-scrollbar{display:none}) so the tiny scrollbar doesn’t appear on iOS Safari.

3 Toolbar Icon → Bottom Sheet
If you prefer to keep the main header minimal, move sorting into the existing FAB “filter” paradigm:

Add a small sort icon just left of the FAB cart.

Tapping it opens a 35 %-height bottom sheet with radio buttons and an “Apply” CTA.

// Trigger (bottom-right corner)
<button
  onClick={()=>setOpen(true)}
  className="fixed bottom-24 right-4 md:hidden p-3 rounded-full bg-white shadow-lg">
  <SlidersIcon className="text-primary-600"/>
</button>

// Sheet body
<Dialog open={open} onOpenChange={setOpen}>
  <Dialog.Content className="fixed bottom-0 inset-x-0 rounded-t-2xl p-6 bg-white">
    <h3 className="text-lg font-semibold text-center mb-4">Sort products</h3>
    {modes.map(m=>(
      <label key={m} className="flex items-center gap-3 py-2">
        <input type="radio" checked={sort===m} onChange={()=>setSort(m)} />
        <span>{m}</span>
      </label>
    ))}
    <button onClick={()=>setOpen(false)} className="mt-4 w-full btn-primary">
      Apply
    </button>
  </Dialog.Content>
</Dialog>
Which should you choose?
Pattern	Pros	Cons
Segmented control	• Instant one-tap
• Clear state	• Limited to ~4 modes
Swipe-able chips	• Scales to many modes
• Matches existing chip UI	• Users may miss horizontal scroll (add subtle fade-edge)
Toolbar sheet	• Keeps header pristine
• Plenty of room for helper text	• Two taps instead of one

Most stores stick with #1 (segmented) when they only need “Price ↑/↓ + Featured.”
If you think you’ll add Newest, Oldest, Best Seller… pick #2.
