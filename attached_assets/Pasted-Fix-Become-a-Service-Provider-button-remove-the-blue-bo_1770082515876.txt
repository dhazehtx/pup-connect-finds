Why there’s a “blank space” with an invisible Add to Cart button (your earlier screenshot)

That usually happens when:

the button exists but text color matches background (e.g., white text on white bg), or

the button is present but has opacity/visibility styles, or

the container reserves height (margin/padding) even if button is visually broken.

If you still see that anywhere: inspect the button → check computed styles for color, background-color, opacity, visibility, display, and height/min-height.
