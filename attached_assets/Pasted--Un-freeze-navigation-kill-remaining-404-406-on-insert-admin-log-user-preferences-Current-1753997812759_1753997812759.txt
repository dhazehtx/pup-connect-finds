### Un-freeze navigation -- kill remaining 404/406 on insert_admin_log + user_preferences

**Current blocking errors**

| Route | Status | Console hint |
|-------|--------|--------------|
| POST /rest/v1/**rpc/insert_admin_log** | 404 (Not Found) | “function public.insert_admin_log not found in schema cache” |
| GET  /rest/v1/**user_preferences?select=*** | 406 | no Accept / Bearer header |

These requests fire every time a nav tab is clicked; the rejected Promises bubble up and React Suspense freezes the page.

---

#### 1  Make insert_admin_log safe

*File *: **client/src/lib/adminLog.ts (new)**  
```ts
import { api } from '@/lib/api';

export async function logNav(event: {from:string; to:string}) {
  try {
    // Call the RPC only if it exists – swallow 404 to avoid UI crash
    const res = await api('rpc/insert_admin_log', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ event_type: 'NAVIGATION', payload: event })
    });
    if (res.status === 404) return;        // function not deployed in prod → ignore
    if (!res.ok) console.warn('admin log error', await res.text());
  } catch (err) {
    console.warn('admin log network error', err);
  }
}
