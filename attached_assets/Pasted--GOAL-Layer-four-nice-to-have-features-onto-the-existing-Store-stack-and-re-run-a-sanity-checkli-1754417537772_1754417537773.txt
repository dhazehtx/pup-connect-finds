4. Analytics hook       → fire `purchase` event to PostHog

──────────────────────── IMPLEMENTATION STEPS ───────────────────────

①  INVENTORY ALERT

• DB
  alter table products add column low_stock_alerted boolean default false;

• Cron / Edge Function (run every hour)
  – query products where inventory_qty < 5 and low_stock_alerted = false
  – send:
      • email via Resend (or NodeMailer) to ops@my-pup.com
      • Slack POST to #ops-alerts (SLACK_WEBHOOK_URL env var)
  – set low_stock_alerted = true

②  DISCOUNT CODES

• New table discounts
  id uuid PK, code text unique, pct_off numeric, starts_at timestamptz,
  ends_at timestamptz, is_active boolean default true

• Extend POST /api/checkout
  – accept { discount_code } optional
  – look up active discount, clamp 1-100 %
  – create line_items with adjustable_amount { amount_off } OR percentage
    (Stripe coupons API)
  – store discount_id on order row

③  JEST TEST

• test/webhook.order.test.ts
  – mock Supabase client (jest.mock('@supabase/supabase-js'))
  – feed sample checkout.session.completed JSON
  – expect insert called once with correct payload

④  ANALYTICS HOOK

• Inside webhook handler (after order insert)
  – import posthog from 'posthog-node'
  – posthog.capture({
        distinctId: session.customer,
        event: 'purchase',
        properties: {
          order_id: <newId>,
          total: session.amount_total / 100,
          currency: session.currency,
          items: line_items.map(li => li.price.product)
        }
      })
