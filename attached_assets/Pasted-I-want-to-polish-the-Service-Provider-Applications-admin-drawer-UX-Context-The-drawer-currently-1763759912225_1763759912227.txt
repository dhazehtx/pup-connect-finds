### Part 1 – Inline ID previews + zoom modal

Inside the “Review Provider Application” drawer:

- In the “ID Verification Documents” section, stop using links or anchors that trigger file downloads (no `download` attribute, no `target="_blank"` unless absolutely necessary).
- Use the `front_image_url` and `back_image_url` fields returned from the API. These are signed URLs to Supabase storage.

Implementation details:
- Render both images as **visible thumbnails by default** (for example, ~100–150px wide).
- Wrap each in a button/div with `cursor: pointer` and an accessible label (e.g. `aria-label="View front of ID"`).
- When a thumbnail is clicked, open a simple image preview modal/lightbox that shows a larger version of that image.
  - You can reuse any existing modal/dialog component from our design system (e.g. `Dialog`, `Sheet`, or a simple custom overlay).
  - The modal should have:
    - The full image
    - A close button (X)
    - Clicking outside the modal should also close it.
- If either `front_image_url` or `back_image_url` is missing, show a short “No front ID image uploaded” / “No back ID image uploaded” message instead of a broken image.

Important:
- Make sure clicking the thumbnail **does not trigger a browser download**.
- The images should be loaded via `<img>` or equivalent, not as direct file downloads.

### Part 2 – Clickable applicant name → profile page

In the same drawer, at the top where the applicant’s name and handle are shown:

- Make the **full name** and **@username** clickable.
- Use the existing routing solution (likely `useNavigate` from `react-router-dom`).
  - If we’re using React Router:
    - `import { useNavigate } from "react-router-dom";`
    - Create `const navigate = useNavigate();`
- When the name or username is clicked:
  - If `detailedApp.user?.username` exists, navigate to `/profile/${detailedApp.user.username}`.
  - If not, but `detailedApp.user_id` exists, fall back to `/profile/${detailedApp.user_id}` or simply disable the link.
- Add basic defensive checks:
  - If there is no username/user_id at all, render it as plain text with no click interaction.
- Style the clickable element to look clearly interactive:
  - e.g. `cursor: pointer`, maybe underline on hover or subtle color change.
