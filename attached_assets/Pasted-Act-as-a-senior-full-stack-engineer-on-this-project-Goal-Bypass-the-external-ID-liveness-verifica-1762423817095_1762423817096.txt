  2) mark the application as "pending manual review",
  3) treat it as a success and allow the user to click **Next**.

Right now the UI shows:
- "Both images uploaded successfully!"

### 1) Backend: replace /api/verify/start with a simple manual-verification handler

Find the Express/TS route that handles `POST /api/verify/start` (I see a `start.ts` file open; use that or the equivalent).

Re-implement it with the following behavior:

- Use the Supabase **admin** client (service role key) to authenticate the user and write to the DB.
- Steps:

  1. Read the bearer token from `Authorization: Bearer <jwt>` and verify it with `supabaseAdmin.auth.getUser(jwt)`.
     - If token is missing or invalid, return `401 { error: 'invalid token' }`.

  2. Read from `req.body` the fields that contain the uploaded image URLs and (if available) the current provider application ID.
     - Expect something like:
       - `frontImageUrl`
       - `backImageUrl`
       - optionally `applicationId`
     - If the two image URLs are missing, return `400 { error: 'frontImageUrl and backImageUrl are required' }`.

  3. Using the Supabase admin client, upsert a row into the **provider_applications** table:
     - If `applicationId` is provided, upsert by that id; otherwise create a new application row linked to the authenticated user.
     - Store the two image URLs in columns such as:
       - `id_front_url`
       - `id_back_url`
     - Set a status/field to indicate manual review is needed. For example:
       - `verification_status = 'pending'`
       - or `status = 'pending_verification'`
       - also optionally set `verification_started_at = now()`.

  4. On success, respond with HTTP 201:
     ```json
     { "ok": true, "verification_status": "pending" }
     ```
     DO NOT call any external liveness / document analysis provider. This endpoint should be completely self-contained and only touch our database.

- Make sure this handler never throws unhandled errors; log the error server-side and return `500 { error: 'internal_error' }` if anything unexpected happens.
