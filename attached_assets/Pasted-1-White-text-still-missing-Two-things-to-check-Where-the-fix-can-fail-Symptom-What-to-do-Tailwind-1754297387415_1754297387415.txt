1 — White text still missing? Two things to check
Where the fix can fail	Symptom	What to do
Tailwind didn’t rebuild after you added the new variant/safelist	DevTools shows the pill still has text-primary-foreground and no rule for [data-state=active] → color:#fff	Stop the dev server → npm run dev again. Tailwind only reads tailwind.config.ts on startup.
Class name typo	The trigger has radix-active:text-white but we registered the variant as radix-active (or vice-versa)	Make sure the variant name in the config and the utility in JSX match exactly. Example:
addVariant('radix-active', '&[data-state="active"]') ⇆ className="radix-active:text-white …"

Quick verification
