3) Nuke yellow outlines on inputs (Email/Password/etc.)

Covers focus state, autofill (iOS/Safari), and any default yellow borders.

CSS

/* Base input look */
input, select, textarea, .form-input, .form-control {
  border:1px solid #d1d5db;              /* neutral gray border */
  outline: none;
  box-shadow: none;
  background:#fff;
  border-radius:12px;
}

/* Focus ring + border (accessible blue) */
input:focus, select:focus, textarea:focus,
.form-input:focus, .form-control:focus {
  border-color:#2563eb !important;
  box-shadow: 0 0 0 3px rgba(37, 99, 235, .25) !important; /* soft blue ring */
}

/* Error state (optional—use this class only when there’s a real error) */
.input-error, .form-control.error {
  border-color:#ef4444 !important;         /* red-500 */
  box-shadow: 0 0 0 3px rgba(239, 68, 68, .2) !important;
}

/* iOS/Safari autofill wipes out yellow background */
input:-webkit-autofill,
input:-webkit-autofill:hover,
input:-webkit-autofill:focus {
  -webkit-box-shadow: 0 0 0px 1000px #fff inset !important;
  -webkit-text-fill-color:#111827 !important; /* gray-900 */
  caret-color:#111827 !important;
  border-color:#2563eb !important;           /* keep blue border when focused */
}


Tailwind equivalents

<!-- Base input -->
class="border border-gray-300 rounded-xl bg-white focus:outline-none focus:border-blue-600 focus:ring-4 focus:ring-blue-600/25"

<!-- Error state (when applicable) -->
class="border-red-500 focus:ring-red-500/20"
