### TASK: make marketplace tabs perfectly symmetrical (no gap)

SCOPE
• ONLY edit client/src/pages/Marketplace/Tabs.tsx
• NO changes to colours, logic, or other components.

DESIGN
┌──────── light rail (gray border) ───────┐
│ [ Pet Services ] [ Pup Box ] [ Store ]  │
└──────────────────────────────────────────┘
When a tab is active the **entire trigger** turns royal-blue with white icon + text, no extra margin.

STEPS
1. Tabs container
   Replace current wrapper with:

   ```tsx
   <Tabs.Root
     defaultValue="services"
     className="inline-flex rounded-full border border-gray-300
                bg-gray-50 p-1 gap-1"
   >
     {/* triggers here */}
   </Tabs.Root>
Trigger component
Replace className with variant util – no margins, full rounding:

<Tabs.Trigger
  value="services"
  className="
    px-4 py-1.5 flex items-center gap-2 text-sm font-medium
    rounded-full transition-all duration-200
    text-primary-700 data-[state=active]:text-white
    data-[state=active]:bg-primary-600
  "
>
  <BriefcaseIcon className="w-4 h-4" />
  <span>Pet Services</span>
</Tabs.Trigger>
– Do the same for Pup Box & Store triggers (change value and icon).

Remove any mx-…, space-x-2, or margin utilities around triggers—you now rely on the gap-1 in the parent for even spacing.

Restart dev server (npm run dev) so Tailwind recompiles.

VISUAL CHECK
• Blue pill touches the rail’s inner border evenly on left & right.
• Hover / focus states still work.
• Inactive pills show gray text on gray-50 background.

### Why this fixes the gap

* The **rail** is now a single rounded container (`p-1`) with `gap-1` between triggers—no manual margins to drift out of sync.  
* Each trigger has `rounded-full`; when active, its blue background exactly fills the parent’s interior padding.  
* Because the blue pill is applied via `data-[state=active]`, the highlight always matches the trigger’s width.
