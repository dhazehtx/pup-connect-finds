2️⃣ Dropdown text turns white after selection (this is a real bug)

You spotted an actual usability issue here — good catch.

The problem

When you:

Open Advanced Filters

Select a service

Dropdown closes

👉 The selected value text becomes white on a white background

That means:

The Select component is inheriting text-white

Likely from:

A parent container

Or a shared .text-white / gradient utility

Or a button base style

✅ The exact cause (what’s happening)

Most likely one of these:

.text-white


or

button { color: white; }


is being applied to the closed select trigger, but the dropdown panel overrides it correctly.

So:

Open menu → text is fine

Closed state → text inherits white ❌

✅ The fix (safe and scoped)

Force black text ONLY for the closed state:

.filter-select-trigger {
  color: #111827 !important; /* gray-900 */
}


If this is a Radix / Headless UI / Shadcn Select, target:

[data-state="closed"] {
  color: #111827;
}


Or more explicitly:

.select-trigger span {
  color: #111827;
}


⚠️ Do NOT remove text-white globally — scope it tightly.
